# As Secret

As Secret

## Usage

``` r
as_secret(x, ...)
```

## Arguments

- x:

  A string

- ...:

  Unused argument needed for method

## Value

An `sm_secret` object. The method invoked depends on the class of `x`;
see
[`as_secret.character()`](https://brancengregory.github.io/googlesecretmanager/reference/as_secret.character.md)
for the supported input.
